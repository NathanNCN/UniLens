# UniLens
> UniLens is a platform that lets students view and submit real university applications to top Canadian schools. By exploring admission profiles, users gain insights into what it takes to get in, from grades and extracurriculars to coursework and personal achievements.

## Tech Stack
- **Frontend:** Next.js, TypeScript, Tailwind CSS
- **Backend:** Golang
- **Hosting:** Vercel, Render
- **Storage:** Supabase 


## Demo
- Link: https://uni-lens.vercel.app/

## Features
- **Search Accepted Applications**
  - Users can explore real applications submitted by students who were accepted into top Canadian university programs.
- **Filter Search**
  - Narrow down results by filtering applications based on school or program
- **Google Authentication**
  - Secure login via Google OAuth
- **Responsive UI**
  - Fully responsive layout built with Tailwind CSS, ensuring a smooth user experience across desktop and mobile devices
